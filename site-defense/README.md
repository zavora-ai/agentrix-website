# agentrix-site-defense

Phase 8 self-defense plus costs: the Security Guard probe verifies the served
release model-free — digest recompute, admission, abuse arithmetic — and files
drift and abuse as incident cards; the Facilities Manager watch turns
certificate, domain, backup and advisory inputs into filed proposals. Every
target run passes the guard: frozen sites skip, quiet hours defer, and skips,
deferrals, denials and incidents all audit. Tenant isolation denies cross-site
card reads and release serves with audit lines, and the release store refuses
foreign serve pointers at the storage layer.

cargo test -p agentrix-site-defense   # the Phase 8 gate
