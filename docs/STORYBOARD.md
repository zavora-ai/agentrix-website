# Demo Storyboard — Agentrix Website

Five beats, ~4 minutes. Each beat lists what the audience sees, what is
actually running, and the honesty label spoken/shown. Rule: anything not
live is said to be not live, on stage, in one clause.

## Beat 1 — The Birth (migration without credentials)

- **Sees**: paste `classyperfumes` (or any volunteer WordPress URL) →
  crawler cards bloom (Pages, Products, Voice) → LaunchGate stamps
  verified claims green, parks unverifiable ones as Held → a World
  crystallizes: Sky, districts, Concierge named by the business.
- **Real**: public crawl → machine twins → BuiltinGenerator rebuild →
  gate checks (claims/links/machine views/migration parity).
- **Label**: "No login, no export file. Everything the gate could not
  verify is waiting for the owner — watch."

## Beat 2 — The Arrival and the Verb (human audience)

- **Sees**: visitor (presenter on phone) lands; Concierge greets in
  Swahili after one tap; "Book Friday for two, somewhere quiet" →
  booking card, editable in place; product question answered with the
  product card attached.
- **Real**: public partition concierge (search + RAG over migrated
  docs), streaming Spark, booking capability with consent.
- **Label**: "The concierge cannot publish, refund, or see the back
  office. That is by design."

## Beat 3 — The Night Shift (owner world)

- **Sees**: flip to Back-Office; time-scrub 00:00→07:00: Watchman holds
  a 03:12 publish (guardrail), Editor blooms a draft in the owner's
  voice with cited claims, two support replies sent in-ladder, one
  held. Owner approves the held pair; spend meter under charter cap.
- **Real**: kernel charter-job wakes, harness ladder + held approvals,
  signed audit chain; incident path is rollback/edge read-only.
- **Label**: recorded ad spend, if shown, is labeled "recorded —
  no live ad adapter yet." Async voice memo labeled async.

## Beat 4 — The Mirror (agentic audience)

- **Sees**: split screen. Left: the World as humans see it. Right:
  Agent View — manifest, trust tiers, a partner agent placing an
  order over AWP: consent receipt, payment held (202), owner approves,
  call completes. Release digests identical on both sides.
- **Real**: AwpEdge v2 capabilities, credential tiers (WebBotAuth),
  idempotency, HeldCall decide.
- **Label**: "Agents are verified by credentials, never by user-agent.
  People never see this skin; agents never scrape the human one."

## Beat 5 — The Ask (close)

- **Sees**: the World, calm at rest. Owner voice-over line.
- **Line**: "Every business already has a website. It just sits there.
  This one worked last night." Freeze switch pressed live; the field
  parks; unfreeze; work resumes. End card: **Agentrix Website —
  the world's first Website 4.0 for the agentic era. By Zavora.**

## Failure choreography

If a live call fails on stage: the card shows the failure honestly
(the harness pattern), presenter falls back to the recorded Night
Shift, and says so. No silent retries, no pre-baked success swaps.
